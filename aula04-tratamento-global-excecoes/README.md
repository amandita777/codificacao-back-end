## ✨ Sobre a aula

Nesta aula foi desenvolvido um servidor utilizando **Node.js** e **Express**, com foco no **tratamento global de exceções e erros**.

A aplicação possui rotas que simulam situações de **sucesso**, **erro síncrono** e **erro assíncrono**, permitindo entender como os erros podem ser capturados, registrados e encaminhados para um único middleware responsável pelo tratamento.

### 🎯 Objetivo

> Criar uma estrutura de tratamento de erros mais organizada, centralizada e padronizada para uma aplicação Back-End.
